## Technical Implementation Notes

### Network Tools
Most network tools will require:
- **Backend API calls** (can't do raw sockets in browser)
- **FastAPI endpoints** for connectivity testing
- **WebSocket support** for real-time monitoring
- **Third-party APIs** for geolocation, BGP lookup
- **Rate limiting** to prevent abuse

Example backend structure:
```python
# backend/network_tools.py
@app.post("/api/tools/network/ping")
async def ping_host(host: str):
    # Implement ping logic
    pass

@app.post("/api/tools/network/traceroute")
async def traceroute(host: str):
    # Implement traceroute logic
    pass

@app.post("/api/tools/network/speed-test")
async def speed_test():
    # Implement speed test logic
    pass
```

### Image Tools
Most image tools can be:
- **Client-side only** using Canvas API
- **No backend required** for basic operations
- **Optional backend** for heavy processing (background removal)
- **Web Workers** for performance

Example client-side structure:
```javascript
// frontend/src/utils/imageProcessing.js
export const extractMetadata = (file) => {
  // Use exif-js library
};

export const applyFilter = (imageData, filter) => {
  // Use Canvas API

  // Use @imgly/background-removal or API
```
