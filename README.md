# DevTools Suite

A comprehensive desktop application with 70+ developer productivity tools.

## Quick Start

### Backend
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 server_desktop.py
```

### Frontend
```bash
cd frontend
npm install
npm start
```

### Build Desktop App
```bash
cd frontend
npm run tauri build
```
