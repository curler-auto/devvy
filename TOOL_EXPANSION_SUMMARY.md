## Tool Naming Conventions

All tools follow consistent patterns:
- **Converters:** `[Source] to [Target]` (e.g., "JSON to YAML")
- **Generators:** `[Type] Generator` (e.g., "UUID Generator")
- **Formatters:** `[Language] Formatter` (e.g., "Python Formatter")
- **Validators:** `[Type] Validator` (e.g., "Email Validator")
- **Builders:** `[Type] Builder` (e.g., "SQL Query Builder")
- **Analyzers:** `[Type] Analyzer` (e.g., "Performance Analyzer")
